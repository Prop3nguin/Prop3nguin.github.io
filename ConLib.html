The Conlang Library

What is it?

Web-App

Currently designed to be run localy on a machine, but posesses the necessary archetacture to easily moved online.

The Conlang Library has the capability to store the necessary information that describes a language. It's a large project that's still in the works, but Im designing it with a miryad of features that will be listed at the bottom of this page.

What's it for?

Valtare

Valtare is the project that started it all. An ambitious me in sixth grade decided that I wante my own language. How hard could it be? Naturally, I only ended up with a new twenty-six glyph alphabet with the exact same phonetics as english at first, but over the next few years I changed it little by little.

I was frustrated at one point when I realised I'd forgotten most of the words I'd come up with for the language. ConLib was my solution. A localy hosted personal Database with a stylish UI and room for even more glamourous features should I need them.

Incarnatum

What Use is a Conlang? Well, the most popular is fantasy worldbuilding. Several large titles did this like Star Wars, Star Trek, Lord of the Rings and Game of Thrones just to name a few.
